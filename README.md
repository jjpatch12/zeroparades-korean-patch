# ZeroParades 한국어 패치

비공식 한국어 패치입니다.

## 다운로드

[릴리즈 페이지에서 패치 받기](https://github.com/jjpatch12/zeroparades-korean-patch/releases/latest)


## 한국어화 범위

| 항목 | 포함 내용 |
| --- | --- |
| 대사와 선택지 | 본편 대사, 선택지, 독백, 설명문, 등장인물 관련 텍스트 |
| 설정과 본편 UI | 설정 탭, 옵션 이름·값·설명, 메뉴와 본편 UI 문구 |
| 아이템·퀘스트 | 아이템과 사고 관련 설명, 행동 선택지, 무기 제작 관련 문구 |
| 번역 검수 | 뜻과 문맥, 캐릭터 말투와 관계, 직역투, 오역, 용어 통일 점검 |


## 설치 방법

1. 게임을 종료합니다.
2. 다운로드한 패치 EXE를 실행합니다.
3. **`ZeroParades.exe`가 있는 게임 폴더**를 선택합니다.
4. **게임 폴더 검사**를 실행한 뒤 **한국어 패치 적용**을 누릅니다.
5. 게임을 실행하고 언어를 **English**로 선택합니다.

이 패치는 English 언어 슬롯에 적용됩니다. 시스템에 글꼴을 별도로 설치할 필요는 없습니다.
