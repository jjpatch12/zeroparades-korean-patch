# ZeroParades 한국어 패치

**게임 버전 1.1.40707 / Windows 64비트**용 비공식 한국어 패치입니다. 대사, 선택지, 설정과 본편 UI, 한글 글꼴, 한국어 UI 이미지를 하나의 설치 EXE에 담았습니다.

## 다운로드

[릴리즈 페이지에서 패치 받기](https://github.com/jjpatch12/zeroparades-korean-patch/releases/latest)

Assets에서 **`ZeroParades_한국어패치_1.1.40707.exe`**를 다운로드하세요. 게임이 설치되어 있어야 사용할 수 있습니다.

## 한국어화 범위

| 항목 | 포함 내용 |
| --- | --- |
| 대사와 선택지 | 본편 대사, 선택지, 독백, 설명문, 등장인물 관련 텍스트 |
| 설정과 본편 UI | 설정 탭, 옵션 이름·값·설명, 메뉴와 본편 UI 문구 |
| 아이템·퀘스트 | 아이템과 사고 관련 설명, 행동 선택지, 무기 제작 관련 문구 |
| 번역 검수 | 뜻과 문맥, 캐릭터 말투와 관계, 직역투, 오역, 용어 통일 점검 |
| 한글 글꼴 | 나눔스퀘어라운드 Regular 기반 호환 글꼴과 누락 글자 보조 글꼴 |
| UI 이미지 | 한국어화한 UI 이미지 4개 |
| 설치 프로그램 | 게임 폴더 검사, 설치 전 백업, 패치 적용, 설치 직전 상태로 복구 |

전체 문자열 레코드 **72,895개**를 포함합니다. 이 가운데 **72,652개**를 검수했고, 검수 제외 **243개**는 기존 문구를 유지했습니다. 포스터 이미지는 원본을 유지합니다.

## 설치 방법

1. 게임을 종료합니다.
2. 다운로드한 패치 EXE를 실행합니다.
3. **`ZeroParades.exe`가 있는 게임 폴더**를 선택합니다.
4. **게임 폴더 검사**를 실행한 뒤 **한국어 패치 적용**을 누릅니다.
5. 게임을 실행하고 언어를 **English**로 선택합니다.

이 패치는 English 언어 슬롯에 적용됩니다. 시스템에 글꼴을 별도로 설치할 필요는 없습니다. 게임 버전은 **1.1.40707**이어야 하며, 지원하는 파일 상태인지 설치 전에 검사합니다.

## 백업과 복구

번들 7개와 목록 파일 2개, 총 **9개 파일**을 교체합니다. 설치 전에 해당 파일을 게임 폴더의 **`ZeroParades_KoreanPatchBackup`**에 백업합니다.

복구하려면 같은 패치 EXE에서 **이전 버전 복구**를 누르세요. 이 기능은 패치 설치 직전의 상태로 되돌립니다. 복구할 때까지 백업 폴더를 보관하세요.

## 글꼴

한글은 **나눔스퀘어라운드 Regular**를 바탕으로 한 호환 글꼴을 사용합니다. 글자 모양과 간격을 유지하면서 빈 글자 매핑을 정리했으며, 파생 글꼴의 내부 이름은 **ZeroParades Round KR**입니다.

나눔에 없는 일부 글자(`퓍`, `無` 등)는 **Noto Sans KR**로 표시합니다. 해당 글자는 모양이 조금 다를 수 있습니다. 기존 영문·숫자·터미널 기호 글꼴은 유지합니다.

- [나눔 글꼴 라이선스](licenses/Naver_Nanum_Official_License.txt)
- [Noto Sans KR 라이선스](licenses/NotoSansKR_OFL.txt)
- [글꼴 호환 처리 내역](licenses/Font_Compatibility_Notice.txt)

## 검증과 오류 제보

문자열 형식과 글꼴의 글자 지원, 패치 파일의 크기·SHA-256, 설치·백업·복구와 실패 시 되돌리기를 확인했습니다. 긴 대사의 줄바꿈과 화면 넘침은 해상도·UI 설정·플레이 장면에 따라 추가 확인이 필요합니다.

오역, 어색한 말투, 글자 누락, 대사창 잘림 또는 설치 오류를 발견하면 [Issues](https://github.com/jjpatch12/zeroparades-korean-patch/issues)에 알려주세요. 게임 버전, 발생 장면, 원문·현재 번역 또는 화면 캡처를 함께 남기면 확인에 도움이 됩니다.
